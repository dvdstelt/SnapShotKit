The screen is already captured when this appears, so nothing moves under the cursor. Before the drag there is only the crosshair and one row of whole-screen actions, so a full capture is a single click. Once a region exists the same actions attach to the corner where the drag ended: save to disk, open in the editor, copy to clipboard, cancel.
